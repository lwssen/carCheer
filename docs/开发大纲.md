# 加油记录 App（carCheer）开发大纲

## 一、项目概述

- **项目名称**：carCheer（加油记账助手）
- **技术栈**：Java + XML（原生 Android）+ Room（SQLite 持久化）+ ViewModel/LiveData
- **最低支持版本**：minSdk 24（Android 7.0），targetSdk 34
- **核心特性**：
  - 记录每次加油的完整信息（金额、油量、单价、里程等）
  - 自动计算油耗（百公里油耗）、单公里成本
  - 数据全部使用 SQLite 保存到手机本地，**全程不联网，不申请任何网络权限**
  - 支持统计图表、多车管理、数据导出/导入（本地文件）

## 二、功能模块设计

### 1. 加油记录模块（核心）

| 字段 | 说明 | 是否必填 |
|---|---|---|
| 加油日期时间 | 默认当前时间，可修改 | 必填 |
| 所属车辆 | 多车时下拉选择 | 必填 |
| 加油站名称 | 文本输入，可保存历史常用站点 | 选填 |
| 油品类型 | 92# / 95# / 98# / 0# 柴油 / 电（可扩展） | 必填 |
| 加油金额 | 元 | 金额、油量至少填一项 |
| 加油量 | 升 | 同上 |
| 单价 | 元/升，输入金额或油量后自动计算，可手动修正 | 自动/选填 |
| 当前总里程表读数 | km | 必填（用于油耗计算） |
| 是否加满 | 布尔值，影响油耗算法 | 必填 |
| 备注 | 文本 | 选填 |

- 录入页联动逻辑：输入金额 + 单价 → 自动算油量；输入油量 + 单价 → 自动算金额。
- 支持记录的**新增、编辑、删除（带二次确认）**。

### 2. 油耗计算模块

- 计算规则（经典"加满箱"算法）：
  - 找到该车辆上一条"加满"记录与本次"加满"记录之间：`油耗 = 区间加油总量 ÷ 区间行驶里程 × 100`
  - 未加满的记录只累计油量，不参与结算
- 展示：每条记录列表项显示本次百公里油耗；详情页显示计算过程
- 加油量缺失或里程倒退等异常数据时跳过计算并给出提示文案

### 3. 统计分析模块

- **概览卡片**：累计加油次数、累计花费、累计加油量、平均油耗、当前油价比上次涨跌
- **趋势图**：近 N 次油耗折线图（自绘 View 或 MPAndroidChart，见"选型说明"）
- **月度汇总**：按月统计花费/油量/里程，列表展示
- **加油站排行**：按站点汇总消费次数与金额（若填写了站点）

### 4. 车辆管理模块

- 多车支持：添加/编辑/删除车辆
- 车辆字段：名称、车牌号（选填）、初始里程表读数、油箱容积（选填）、备注
- 删除车辆时提示将级联删除其下所有记录，二次确认

### 5. 数据管理模块

- **导出**：所有记录导出为 CSV（保存到下载目录，MediaStore API，无需存储权限）
- **导入**：从 CSV 导入（字段与导出格式一致）
- **清空数据**：二次确认
- 数据备份为可选后期增强（导出 JSON 完整备份）

### 6. 历史查询模块

用于查询任意时间段的历史加油数据，入口在底部导航栏"统计"右侧，新增"历史"Tab（导航顺序：首页 / 统计 / 历史 / 设置）。

**页面布局（自上而下）：**

1. **时间范围行**：开始日期 + 结束日期两个日期输入框（点击弹出日期选择器）
2. **筛选行一：时间类型下拉**（选择后自动反算开始/结束日期并刷新列表）
   - 本月：当月 1 日 ~ 今天（或月末，取自然月）
   - 近三月：今天往前推 3 个自然月
   - 近半年：今天往前推 6 个自然月
   - 自定义：手动通过日期选择器修改开始/结束日期，默认"本月"
3. **筛选行二：数据类型下拉**
   - **全部**：展示时间范围内所有加油记录，按时间倒序
   - **最高油价**：展示时间范围内单价最高的一条（或并列多条）记录，并突出显示
   - **最高加油金额**：展示时间范围内金额最大的一条（或并列多条）记录，并突出显示
4. **结果列表**：复用记录列表样式（日期 / 金额 / 油量 / 单价 / 油耗 / 加满标记），分页加载（每页 6 条，触底翻页追加）

**查询规则：**

- 查询范围为"当前选中车辆"（与记录页的车辆选择联动）
- 时间条件按记录的加油日期（含边界，即 >= 开始日期 00:00、<= 结束日期 23:59:59）
- 修改任一筛选条件（时间类型 / 数据类型 / 起止日期）立即按新条件重新查询第一页
- 时间范围内无数据时显示空态提示"该时间段内暂无加油记录"
- 数据类型为"最高油价 / 最高加油金额"时，仅统计该字段非空的记录；若范围内所有记录该字段为空，给出提示文案

## 四、数据层设计（Room）

### 实体（Entity）

```java
// 车辆表
@Entity(tableName = "vehicles")
public class Vehicle {
    @PrimaryKey(autoGenerate = true) public long id;
    @NonNull public String name;          // 车辆名称
    public String plateNo;                // 车牌号
    public double initialOdometer;        // 初始里程
    public double tankCapacity;           // 油箱容积，可为空值语义
}

// 加油记录表
@Entity(tableName = "refuel_records",
        foreignKeys = @ForeignKey(entity = Vehicle.class,
            parentColumns = "id", childColumns = "vehicleId",
            onDelete = ForeignKey.CASCADE),
        indices = {@Index("vehicleId"), @Index({"vehicleId", "odometer"})})
public class RefuelRecord {
    @PrimaryKey(autoGenerate = true) public long id;
    public long vehicleId;
    public long date;          // 时间戳毫秒
    public String station;     // 加油站
    public String fuelType;    // 油品类型
    public Double amount;      // 金额（元），可空
    public Double volume;      // 油量（升），可空
    public Double price;       // 单价（元/升），可空
    public double odometer;    // 里程表读数
    public boolean fullTank;   // 是否加满
    public String note;
}
```

### DAO 要点

- `RecordDao`：按车辆+日期倒序查询、插入、更新、删除；查询某车辆最近一次加满记录；按月聚合统计（`SUM`/`GROUP BY strftime`）
- `VehicleDao`：增删改查，车辆及其记录数联查
- 统计类查询返回 POJO（非 Entity），配合 LiveData 供 UI 观察

### Database

- `AppDatabase extends RoomDatabase`，单例模式
- `version = 1`，schema 导出开启（便于以后写 Migration）
- 全部 DAO 查询走 `ViewModel + LiveData`，禁止在主线程操作数据库

## 八、测试要点

- 油耗算法单元测试：加满→加满、中途未加满、金额/油量缺失、里程倒退、首条记录
- 表单联动计算测试（金额↔油量↔单价三角换算，注意精度与四舍五入）
- 数据库 Migration 演练（版本升级不丢数据）
- 导出 CSV 用 Excel/WPS 打开验证中文编码（UTF-8 BOM）
- 历史查询单元测试：时间类型反算日期区间（本月/近三月/近半年跨年场景）、边界日期包含、最高油价/最高金额并列取多条、范围内无记录空态

## 九、风险与待定项

1. ~~图表库~~ **已确定：MPAndroidChart v3.1.0**（需引入 jitpack 仓库，仅构建期联网，运行期仍不联网）。
